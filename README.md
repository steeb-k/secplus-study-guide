## Suggested study loop

1. Read a domain file (start with `00-exam-overview.md`).
2. Take that domain's module quiz (practice mode first, exam mode once comfortable). Repeat until **3 consecutive attempts at 83% or higher**.
3. Move to the next domain.
4. Run the **missed-question drill** after each domain and again before final exams.
5. Review `90-`, `91-`, and `92-` the week before the exam.
6. Take full final exams until you are **consistently at or above 750 estimated**.
